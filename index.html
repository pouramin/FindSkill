How to read this test

What we learned

1. Installed isn't invoked

In the automatic-discovery test, find-skills was available but not read. Its mere presence did not trigger discovery.

2. Explicit guidance changes the task

Reading three named skills on request tests compliance with an instruction, not spontaneous skill discovery.

3. Project policy is a separate test

The AGENTS.md variant adds a standing skill-discovery policy; its README records discovery and approved skill use.
