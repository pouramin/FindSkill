# AERON

A complete fictional sneaker storefront built with React, TypeScript, Vite, and plain CSS.

## Preview

Run `npm install` (first time only), then `npm run dev` and open the Local URL printed in your terminal, normally http://localhost:5173.

## Production

`npm run build` runs the TypeScript checks and creates `dist/`. Run `npm run preview` to serve that build.

## Features

Six products, category filters, product details, EU size selection and validation, persistent shopping bag, quantity controls, item removal, shipping and total calculations, mobile navigation, brand story, newsletter form validation and local confirmation, and informational dialogs.

The newsletter is a frontend demonstration and does not transmit or save email addresses. Checkout is intentionally unavailable. Cart data stays in browser localStorage. Local product photography is sourced from Unsplash and is illustrative; AERON is a fictional brand. Each image has a local SVG fallback. Google Fonts are optional; system font fallbacks are included.

Keyboard support includes visible focus indicators, dialog focus containment, Escape to close, and focus restoration. Reduced-motion preferences are respected.
