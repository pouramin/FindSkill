# AERON

A fictional premium sneaker store built with React, TypeScript, Vite, and plain CSS.

## Preview

Run `npm install` once, then `npm run dev` and open the Local URL Vite prints (normally http://127.0.0.1:5173).

Run `npm run build` for a checked production build. Run `npm run preview` to serve `dist`.

## Features

- Six sneaker colorways, category filtering, and price sorting.
- Accessible product dialogs, EU size selection, and validation.
- Shopping bag with quantity limits, removal, shipping calculation, and local persistence.
- Responsive navigation, brand story, newsletter form, and informational footer dialogs.
- Local original SVG sneaker illustrations; no external product image dependencies.
- Reduced-motion support, keyboard focus styles, modal focus trapping, and Escape dismissal.

This is a browser-only demonstration. It never processes payments or places orders. Newsletter submissions are saved locally and do not send emails. Google Fonts enhance typography; system sans-serif fallbacks work offline.
